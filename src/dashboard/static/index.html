Why We Talk About What We DON'T Protect Against (Honest Engineering)

What SealArena Eliminates in Software: Cross-tenant network probing, shared filesystem leakage, environment snooping, prompt extraction via multi-tier canaries, side-channel response latency inference (padded to 350ms), and audit log tampering via Ed25519 hash chains.

Honest Engineering Boundary: A pure software sandbox on standard cloud VMs cannot defend against a physical attacker with direct DRAM bus probes or a compromised host ring-0 hypervisor. Microarchitectural cache timing (e.g. Spectre/Meltdown, Rowhammer) requires hardware confidential computing (AMD SEV-SNP or Intel SGX). We design SealArena so confidential containers can be layered on top with zero application rewrite.
